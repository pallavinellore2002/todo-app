# Todo Entity

The Todo entity represents a task that a user wants to track.

| Field | Type | Required | Default | Generated By | Description |
|---|---|---|---|---|---|
| `id` | INT | Yes | None | MySQL | Unique identifier for the todo |
| `title` | VARCHAR(255) | Yes | None | User | The task description |
| `completed` | BOOLEAN | Yes | `false` | MySQL | Whether the todo is completed |
| `created_at` | DATETIME | Yes | Current timestamp | MySQL | When the todo was created |
| `updated_at` | DATETIME | Yes | Current timestamp | MySQL | When the todo was last updated |

## Field Rules

### id
- Primary key.
- Unique for every todo.
- Auto-incremented by MySQL.

### title
- Required.
- Must be a string.
- Must not be empty.
- Must not contain only whitespace.
- Maximum length is 255 characters.

### completed
- Required.
- Boolean value.
- Defaults to `false` when a todo is created.
- Can be changed between `false` and `true`.

### created_at
- Required.
- Automatically generated when the todo is created.
- Must not change when the todo is edited.

### updated_at
- Required.
- Automatically generated when the todo is created.
- Must change whenever the todo is updated.

## Entity Relationships

The current Todo application has no relationships to other entities.

Each Todo is an independent record.
